## Skills de Dominio

| Skill | Comando | Descripción |
|---|---|---|
| `python-blender-addon-agent-skill` | `$blender` | Addons/extensiones Blender 4.2+ / 5.x+ (bpy) |
| `python-fastapi-pydantic-agent-skill` | `$fastapi` | APIs REST asíncronas y validación Pydantic v2 |
| `python-langchain-agents-agent-skill` | `$langchain` | Agentes IA, RAG y cadenas LLM |
| `python-pandas-data-agent-skill` | `$pandas` | DataFrames, ETL y análisis numérico |
